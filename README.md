# Pamoza Restaurant Website

Responsive React + Tailwind CSS + Vite landing page for Pamoza — Restaurant, Delivery, Community.

## Run

```bash
npm install
npm run dev
```

Production build: `npm run build`. Preview: `npm run preview`.

## Included

- Responsive restaurant landing page and mobile navigation
- Pamoza-inspired navy, blue, yellow and brown visual system
- Heritage-inspired geometric vector pattern
- Menu categories and sample meal cards
- Working local meal-enquiry basket with copy-to-clipboard
- Dine-in, takeaway and delivery information
- Self-contained SVG illustration (no broken image asset references)

## Before going live

The restaurant logo is represented as a vector approximation in this GitHub version. Replace it with the final approved Pamoza logo asset. Replace illustrative menu items with official menu, prices, photographs, phone number, address, opening hours and actual ordering integration. Enquiry basket is a demo; it does not place real orders or process payments.
